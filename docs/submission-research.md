[API metadata](https://registry.npmjs.org/powerbi-visuals-api/latest), [tools metadata](https://registry.npmjs.org/powerbi-visuals-tools/latest). On 2026-10-04, the 7.2.1 npm package remained the latest installable tools release: the 7.2.2 GitHub release supplies only `lib.zip`, not a complete npm package, and the configured Microsoft feed returned E404. Do not fabricate or vendor an installable package from that asset. The Learn changelog lagged at 5.10.0; illustrative old API versions in project examples are not a current recommendation. Version currency does not prove minimum supported Desktop compatibility.

High contrast and keyboard have dedicated Microsoft implementation guidance and must be substantiated when advertised; the inspected publishing policy does not establish them as independent universal certification gates. [High contrast](https://learn.microsoft.com/en-us/power-bi/developer/visuals/high-contrast-support), [keyboard](https://learn.microsoft.com/en-us/power-bi/developer/visuals/supportskeyboardfocus-feature). [Localization](https://learn.microsoft.com/en-us/power-bi/developer/visuals/localization), [non-English policy](https://learn.microsoft.com/en-us/legal/marketplace/certification-policies#10014-non-english-content).

## Honest internal workflow comparison

| Alternative | Publicly demonstrated capabilities | Defensible Atlyn distinction |
|---|---|---|
| Native Matrix | Rows/columns/values, hierarchies, totals and frozen row headers. Conditional backgrounds/fonts, rules, data bars and icons can express exceptions. [Matrix](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-matrix-visual), [conditional formatting](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-conditional-table-formatting) | Matrix is a credible baseline, not an incapable competitor. Atlyn packages one explicit allocation/capacity contract with zero/missing/duplicate/partial states, next-overload navigation and full details. No measured authoring-time/readability superiority is claimed. |
| xViz Gantt Resource mode | Resource planning/allocation mode with multiple task/phase bars per row, execution intervals, and conditional formatting of progress/milestones/timeline bars. [Resource Gantt](https://docs.xviz.com/project-management/resource-gantt), [conditional formatting](https://docs.xviz.com/project-management/alerting-techniques/conditional-formatting) | There is real overlap in resource visibility. Atlyn's scope is an authoritative period-capacity matrix, not a replacement for task-duration timelines. The inspected pages do not establish that xViz lacks capacity measures, equivalent matrix functions or writeback. |
| xViz broader Gantt | Planned/baseline bars and dependency connectors. Its critical-path example prepares flags in Power Query before displaying them. [Planned bars](https://docs.xviz.com/project-management/planned-bars), [connectors](https://docs.xviz.com/project-management/connectors), [critical path](https://docs.xviz.com/project-management/tips-and-tricks/critical-path-in-gantt-chart) | Atlyn does not claim scheduling, leveling, dependency management or critical-path computation. No price, performance or market-leadership advantage is established. |

The local sample demonstrates the Atlyn exception workflow and retains native comparison pages, but xViz was researched through vendor documentation, not installed/benchmarked. **Keep this comparison out of Marketplace listing copy and keywords:** policy prohibits comparative marketing and competitor keywords. [Description policy](https://learn.microsoft.com/en-us/legal/marketplace/certification-policies#10013-description), [keywords](https://learn.microsoft.com/en-us/legal/marketplace/certification-policies#10022-keywords).

storefront subscriptions; visuals are ungated with free shared viewing. Runtime
licensing and paid-author enforcement are not required. This decision is not a
Microsoft policy conclusion or a source-license change.

existing commercial terms, support/privacy/EULA, languages/geographies, reviewer
access, screenshot-size discrepancy, the official Power BI certification request,
native PBIX/host acceptance, certification timing, final submission and go-live
remain owner/parent responsibilities. Standard Contract selection can constrain
later contract changes; do not invent this choice.
[Contract options](https://learn.microsoft.com/en-us/partner-center/marketplace-offers/power-bi-visual-properties#use-the-standard-contract).

The owner clarified on 2026-09-10 that the requested badge is Microsoft's
official **Power BI certified** badge, not a separate graphic or the IAP
"additional purchase" label. There is no parent badge asset/placement blocker.
Do not add an in-visual badge or claim certification before Microsoft grants it.
Native results remain forthcoming and submission stays behind the final parent
gate.

Certification is optional and is not automatic for later updates. Microsoft recommends publishing before requesting certification if certification would delay availability; the owner's release strategy controls that decision.
